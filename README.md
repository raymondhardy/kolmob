# Kolmob

An unofficial Android port of [KoLmafia](https://github.com/kolmafia/kolmafia), the
Kingdom of Loathing helper. Kolmob runs KoLmafia's real core headless on the phone
(the ASH script interpreter, the request layer and the data files) with a mobile-first
interface on top, instead of the desktop Swing windows.

## What works

- Adventure screen with location picker, turn counts, stop conditions, fight actions,
  combat scripts, auto-attack, choice-adventure settings and a live log
- Character: gear, outfits, skills, effects, familiars, eating, drinking and spleen
- Tools: mall, crafting, NPC shops, coinmasters, your store, clan and stash, mail,
  chat with unread counts and notifications, diet planner, maximizer, moods,
  preferences, session logs, item/monster database, and more
- A script editor and runner for ASH scripts (with line numbers, find, error lines)
- A relay browser (the Game tab) with KoLmafia's own relay features
- Script repositories via git and svn

## Building

Requirements: JDK 21, the Android SDK (compileSdk 34, minSdk 33), and a checkout of
upstream KoLmafia.

```sh
git clone https://github.com/kolmafia/kolmafia ~/workspace/kolmafia
tools/sync-upstream.sh ~/workspace/kolmafia   # copies the core in and applies the Android overrides
./gradlew :app:assembleDebug
```

`kolmafia-core/src/` is generated by the sync script and is intentionally not committed.
Android-specific replacements for upstream files live in `kolmafia-overrides/`; Swing and
AWT shims live in `compat/` and `compat-gen/`. `kolmafia-core/UPSTREAM_VERSION` records
the upstream commit this was built against.

Release signing reads an untracked `keystore.properties` in the project root
(`storeFile`, `storePassword`, `keyAlias`, `keyPassword`). Never commit it.

## Development helpers

`tools/` has an emulator UI driver and a navigation check (`tools/navcheck.py`) that
verifies the bottom navigation is visible on every screen. `tools/dev-login.sh` signs the
debug build in from an untracked `auth` file (`user=...` and `pass=...`); that file is
git-ignored and must stay local.
